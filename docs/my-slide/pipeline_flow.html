2.3. FastAPI Server + RAG Pipeline

POST /api/v1/ai/analyze — end-to-end request flow with infrastructure

🔽 STEP 1 — Incoming Request
POST /api/v1/ai/analyze JWT Auth
Request body: { code, language, user_id } · JWT verified against Node.js backend shared secret (HS256)
⚡ STEP 2 — Cache Lookup
Redis GET SHA256(code+language)
HIT → return cached result in <5ms · MISS → continue pipeline · Graceful degradation: Redis down → skip cache, server keeps running
🔧 STEP 3 — AST Preprocessing (AI1 Module · Ân)
ast_preprocessor.py — Extract structure + keywords
stripComments() → normalizeWhitespace() → extractFunctions() → extractKeywords()
Backend: @babel/parser (JS) · ast module (Python)
🔍 STEP 4a — BM25 Retrieval (AI2 · Trung)
bm25_module.py · 2050-doc Index
CamelCase-aware tokenizer · Top-3 relevant docs retrieved · In-memory, <500ms load · auto_stopwords for scaling
🤖 STEP 4b — LLM Inference (AI2 · Trung)
rag_pipeline.py → build_prompt() → LLMClient Semaphore(3)
Prompt = System instruction + 3 retrieved docs + user code
LLM Backend: Mock (dev) → OpenAI (staging) → HuggingFace/Ollama (production)
📦 STEP 4c — Output Parser (AI1 Module · Ân)
output_parser.py — Extract code blocks
Parse raw LLM output → extract markdown code blocks → { suggestions[], explanation }
Handles: no blocks, multiple blocks, repetition, edge cases
🛡️ STEP 5a — Race Condition Scan (AI2 · Trung)
race_detector.py · 10 Patterns
Rule-based on AST nodes · No LLM needed · 5 JS + 5 Python patterns
Graceful fallback if ast_preprocessor unavailable
📋 STEP 5b — Report Formatter (AI2 · Trung)
report_formatter.py → format_report()
Dedup by pattern_id + line_range · Classify severity: high / medium / low
FP suppression: Lock present → suppress patterns 7, 8, 10
🔗 STEP 6 — Merge Response
suggestions[] + race_conditions[] → AnalyzeResponse
Combine LLM output + race detector results into unified JSON · Attach metadata: docs_used, model, tokens_used
💾 STEP 7a — MongoDB History (AI2 · Trung)
db.py · Motor Async Driver
Save to ai_analysis_history collection · Paginated GET /history/{user_id}?page=1&limit=20
Index on (user_id, created_at) for efficient queries
⚡ STEP 7b — Redis SET (AI2 · Trung)
cache.py · set_cached() TTL 24h
Key = ai2:analysis:SHA256(code|language) · TTL = 86400s (24 hours)
Next identical request → cache HIT → return in <5ms
✅ STEP 8 — Response to Frontend
JSON AnalyzeResponse → Frontend (React)
{ suggestions: [...], race_conditions: [...], docs_used: [...], model, tokens_used, cached }
