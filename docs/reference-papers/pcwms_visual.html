Hai Công Cụ Được Mô Phỏng

🐛 ThreadSanitizer (TSan)

Phát hiện Data Race - Khi 2 thread cùng truy cập vùng nhớ, ít nhất 1 cái ghi, không đồng bộ.

// OpenMP parallel code — có data race
#include <omp.h>
double dotProduct = 0.0;

#pragma omp parallel for
for (int i = 0; i < n; i++) {
    dotProduct += a[i] * b[i]; // RACE!
}
PCWM học được: Nhận ra pattern += bên trong vòng lặp song song không có reduction clause.

Chìa Khóa Thành Công: Hindsight CoT

Đóng góp lớn nhất của bài báo. Nếu bắt LLM tự suy luận rồi đoán (A Priori CoT), nó sẽ liên tục đoán sai và học cách suy luận sai lệch, dẫn tới sụp đổ mô hình.

Thất Bại (Collapse 49.3%)

A Priori CoT (Tự Mò)

  1. Hỏi LLM: "Code này có lỗi không? Giải thích."
  2. LLM giải thích sai luồng song song.
  3. LLM đưa ra kết quả sai.
  4. Train model với data sai -> Model học cách trả lời bừa 1 đáp án cố định để giảm Loss.
🤦‍♂️
Thành Công (Accuracy 73%)

Hindsight CoT (Biết Kết Quả Trước)

  1. Chạy công cụ thật để lấy kết quả y đúng.
  2. Hỏi Teacher LLM: "Code có kết quả là y. Hãy phân tích từng bước TỪ CODE dẫn đến y."
  3. Teacher sinh ra lời giải thích tự nhiên, chính xác.
  4. Train model (Student) với quy trình suy luận chuẩn này.
Nguyên tắc cốt lõi: Phải suy luận Causal (Từ nguyên nhân -> kết quả), không được nói "Vì tôi biết kết quả là X nên...".
