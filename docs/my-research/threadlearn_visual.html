Await Trap — Interleaving giữa các await

Mỗi await là điểm nhường CPU. Request B có thể chạy xen giữa hai await của Request A → atomicity violation dù dùng async/await.

❌ Buggy — Atomicity Violation

async function transferMoney(fromId, toId, amount) {
  // await 1 — yield point!
  const from = await db.get(fromId);
  // ← Request B chạy vào đây!
  const to   = await db.get(toId);
  // await 2 — yield point!
  from.balance -= amount;
  to.balance   += amount;
  await db.set(fromId, from); // stale!
  await db.set(toId,   to);
}

✅ Fixed — Atomic Transaction

async function transferMoney(fromId, toId, amount) {
  // Toàn bộ read-modify-write trong 1 transaction
  await db.transaction(async (tx) => {
    const from = await tx.get(fromId);
    const to   = await tx.get(toId);
    from.balance -= amount;
    to.balance   += amount;
    await tx.set(fromId, from);
    await tx.set(toId,   to);
  });
  // Nếu bất kỳ bước nào fail → rollback toàn bộ
}

4. 5 Race Condition Patterns (JavaScript)

Closure Loop Variable

closure_loop_var

❌ Bug

for (var i = 0; i < 3; i++) {
  setTimeout(() =>
    console.log(i), 0
  );
}
// Prints: 3, 3, 3

✅ Fix

for (let i = 0; i < 3; i++) {
  setTimeout(() =>
    console.log(i), 0
  );
}
// Prints: 0, 1, 2

var có function scope — tất cả closures share cùng i. let tạo binding mới cho mỗi iteration.

Shared Var + setTimeout

shared_var_settimeout

❌ Bug

let counter = 0;

async function inc() {
  const tmp = counter;
  await delay(1);
  counter = tmp + 1;
}
// race: lost increment

✅ Fix

let counter = 0;

async function inc() {
  // atomic read-modify-write
  counter++;
}
// hoặc dùng queue/mutex

Shared state bị modified sau await — interleaving làm lost update.

Promise No Await

promise_no_await

❌ Bug

async function save(data) {
  // MISSING await!
  db.insert(data);
  sendResponse('ok');
  // insert chưa xong
}

✅ Fix

async function save(data) {
  await db.insert(data);
  sendResponse('ok');
  // insert đã xong ✓
}

Fire-and-forget promise → order violation, response trả về trước khi data được lưu.

Concurrent Write Array

concurrent_write_array

❌ Bug

const results = [];

await Promise.all(
  items.map(async item => {
    const r = await fetch(item);
    results.push(r); // race!
  })
);

✅ Fix

// Return values, không mutate
const results = await Promise.all(
  items.map(async item => {
    const r = await fetch(item);
    return r; // safe!
  })
);

Push vào shared array từ concurrent async callbacks → interleaved writes.

Counter No Atomic

counter_no_atomic

❌ Bug

let count = 0;

app.get('/visit', async (req, res) => {
  const c = count;
  await log(c);
  count = c + 1; // stale!
  res.json({count});
});

✅ Fix

let count = 0;

app.get('/visit', async (req, res) => {
  count++; // increment trước await
  await log(count);
  res.json({count});
});

Non-atomic read-modify-write xung quanh await → lost increments dưới concurrent load.

Bước 1: AST Preprocessor

// Input: raw JS code
function preprocessCode(source) {
  const stripped = stripComments(source);     // xóa // và /* */
  const normalized = normalizeWhitespace(stripped); // chuẩn hóa indent
  const functions = extractFunctions(normalized); // list function names
  const keywords = extract_keywords(normalized);  // top-20 identifiers → RAG
  return { stripped, normalized, functions, keywords };
}

Bước 2: Race Detector — Pattern Matching O(n)

// race_detector.py — detect closure_loop_var pattern
def detect_closure_loop_var(code):
  lines = code.splitlines()
  results = []
  for i, line in enumerate(lines):
    # Tìm "for (var i" hoặc "for(var i"
    if re.search(r'for\s*\(\s*var\s+\w+', line):
      # Kiểm tra body có closure với async callback
      block = '\n'.join(lines[i:i+10])
      if re.search(r'setTimeout|setInterval|\.then|async', block):
        results.append({
          'pattern_id': 'closure_loop_var',
          'line_range': [i+1, i+10],
          'description': 'var i shared across async callbacks'
        })
  return results
